# Lemmatizer

`Lemmatizer` turns inflected word forms into their lemma, or dictionary form. The module also holds the plain functions `lemmatize()` for a single token, `text_lemmatizer()` and `lemma_iterator()` for raw text, and `is_known()` to test whether a word is present in a language's data.

::: simplemma.lemmatizer
